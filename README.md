# DevEstimator Pro

DevEstimator Pro (ScopeIt) is a dynamic single-page web application designed for freelancers and software engineers to estimate project costs, buffers, and timelines dynamically based on complexity and tech stack add-ons.

## Features
- Dynamic cost and timeline calculations.
- Multi-currency support (MAD, USD, EUR).
- Visual project phase breakdown.
- Client-ready PDF export functionality.

## Setup
Simply open `index.html` in any web browser to run the application locally.
